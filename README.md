# CS 1501 devcontainer test

## Overview:
- A simple repo with a `.devcontainer/` directory to test your local development setup

## Notes/Hints:
- The default file to run is `./app/src/main/java/cs1501_test/App.java`, you can execute this by running `./gradlew run`
    - Note the Java package name is `cs1501_test`
- Running `./gradlew test` will run the provided tests in `./app/src/test/java/cs1501_test/BasicTests.java`.
