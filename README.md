# CS 1501 devcontainer test

## Overview:
- A simple repo with a `.devcontainer/` directory to test your local development setup

## Specifications:

## Submission Guidelines:
* **DO NOT** add the `./app/build/` diectory to your repository.
    * Leave the `./app/build.gradle` file there, however

## Additional Notes/Hints:
* The default file to run is `Done.java`, you can execute this by running `./gradlew run`
* Running `./gradlew test` on Linux or macOS will run the tests to check both `Done.java` and `Extra.java`.
